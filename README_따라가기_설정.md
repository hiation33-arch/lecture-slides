# 실시간 따라가기 설정 안내 (처음 한 번, 약 20분)

수업 중 "강사가 넘기면 학생 화면도 같이 넘어가는" 기능을 켜는 방법이에요.
**설정하지 않아도** 슬라이드는 그대로 동작합니다. (학생이 각자 넘겨보는 방식)

준비물: 구글 계정, 이 폴더 전체, GitHub Pages(이미 쓰는 `hiation33-arch.github.io`)

---

## 0. 먼저 연습해 보기 (설정 없이, 5분)

같은 브라우저에서 탭 두 개를 열어요.

- 탭 A (강사): `index.html?teacher&mock&room=TEST`
  - 오른쪽 위 강사 버튼 → 수업 연결 → 아무 이메일/비밀번호나 넣고 로그인
- 탭 B (학생): `index.html?mock&room=TEST`

탭 A에서 슬라이드를 넘기면 탭 B가 따라와요. 탭 B에서 직접 넘기면 "자유 보기"가 되고, 상단 칩을 누르면 다시 따라가요. `mock`은 연습용이라 같은 브라우저 안에서만 연결됩니다.

## 1. Firebase 프로젝트 만들기

1. https://console.firebase.google.com 접속 → **프로젝트 추가**
2. 이름: 예) `lecture-sync` → Google 애널리틱스는 **끔** → 만들기

## 2. Realtime Database 만들기

1. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**
2. 위치: 가까운 곳(싱가포르 등) 선택 → **잠금 모드**로 시작
3. 만들어진 뒤 화면 위쪽의 주소(`https://....firebasedatabase.app`)를 기록해 두세요. 이게 `databaseURL`이에요.

## 3. 강사 로그인 계정 만들기

1. **빌드 → Authentication → 시작하기 → 로그인 방법 → 이메일/비밀번호 사용 설정**
2. **사용자 탭 → 사용자 추가**: 바람님 이메일과 새 비밀번호(다른 곳에서 쓰지 않는 것)
3. 만들어진 사용자의 **사용자 UID**(긴 영문·숫자)를 복사해 두세요.

## 4. 보안 규칙 넣기 (가장 중요)

Realtime Database → **규칙** 탭에 아래를 붙여넣고 `여기에_내_UID`를 3번에서 복사한 UID로 바꾼 뒤 **게시**.

```json
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": true,
        ".write": "auth != null && auth.uid === '여기에_내_UID'"
      }
    }
  }
}
```

의미: 누구나 수업방을 **읽을** 수 있지만, **쓰기**(슬라이드 이동·자료 추가)는 바람님 계정만 가능해요.

## 5. 웹 앱 등록하고 설정값 붙이기

1. 프로젝트 개요 → **웹(</>) 아이콘** → 앱 닉네임 입력 → 등록 (Hosting은 체크 안 함)
2. 화면에 나오는 `firebaseConfig`의 값을 `js/config.js`에 옮겨요.

```js
window.LECTURE_CONFIG={
  firebase:{
    apiKey:"AIza...",
    authDomain:"lecture-sync.firebaseapp.com",
    databaseURL:"https://lecture-sync-default-rtdb.asia-southeast1.firebasedatabase.app",
    projectId:"lecture-sync",
    appId:"1:...:web:..."
  }
};
```

`apiKey`는 비밀번호가 아니라서 공개돼도 괜찮아요. 막아 주는 건 4번의 규칙이에요.

## 6. 허용 도메인 추가

Authentication → **설정 → 승인된 도메인 → 도메인 추가**: `hiation33-arch.github.io`

## 7. 올리고 확인하기

1. 폴더 전체를 GitHub Pages 저장소에 올려요. (`js/`, `img/`, `practice/` 포함)
2. 강사용: `https://hiation33-arch.github.io/저장소이름/?teacher&room=수업코드`
   - 강사 버튼 → **수업 연결** → 3번의 이메일/비밀번호로 로그인
3. 학생용: 표지의 QR을 띄우면 돼요. 같은 수업코드가 들어 있어요.
4. 폰 하나를 학생처럼 열어서 따라오는지 수업 전에 한 번 확인하세요.

## 수업 중 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 학생이 따라오게 | 그냥 넘기면 돼요. 기본이 따라가기예요. |
| 학생이 혼자 둘러본 뒤 | 학생이 상단 칩을 누르면 복귀해요. |
| 전원을 지금 슬라이드로 | 강사 서랍 → **모두 여기로** |
| 슬라이드 건너뛰기 | 강사 서랍 → 슬라이드 목록 체크 (학생에게도 반영) |
| 자료 링크 공유 | 강사 서랍 → 자료 추가 (제목 + 구글 드라이브 공유 링크) |
| 새 수업방 | 수업코드 옆 새로 만들기 → QR이 새 코드로 바뀌어요. |

- 드라이브 자료는 **링크가 있는 모든 사용자 → 뷰어**로 공유해야 학생이 열 수 있어요.
- 강사 메모(비공개) 슬라이드는 학생에게 전달되지 않고 학생은 열 수 없어요.
- 자료 링크는 `http(s)://`만 허용돼요.

## 문제가 생기면

- **칩이 "연결 안 됨"**: `config.js` 값이 비었거나 databaseURL 오타예요.
- **로그인 실패**: 3번의 이메일/비밀번호 확인, 6번 도메인 추가 확인.
- **이동은 되는데 학생이 안 따라옴**: 규칙의 UID가 로그인 계정 UID와 같은지 확인.
- **permission_denied**: 4번 규칙의 UID 확인.
- 무료(Spark) 요금제는 동시 접속이 약 100개라 학생 30명 수업에는 충분해요.
- 완전히 실패해도 학생들은 각자 넘겨보는 방식으로 수업을 계속할 수 있어요.
