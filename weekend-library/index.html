프롬프트 A · 주말 행사 비서

너는 구글 Apps Script를 처음 쓰는 사람을 돕는 코딩 선생님이야. 아래 사양대로 Code.gs를 만들어 줘.

[1. 목표]
구글 시트 메뉴로 한국관광공사 TourAPI에서 행사를 찾아 시트에 정리하고, 내가 체크한 행사만 구글 캘린더에 넣는 도구.

[2. 환경]
- 구글 시트에 연결된 Apps Script(컨테이너 바인딩). 파일은 Code.gs 하나. 외부 서버와 라이브러리는 쓰지 않는다.
- 초보자가 읽을 수 있게 한국어 주석을 충분히 달고, 코드를 '설정값 / 메뉴 / 인증키 / API 호출 / 거르기 / 시트 쓰기 / 캘린더 / 메뉴 동작' 구역으로 나눈다.
- 코드 맨 위에 const로 설정값을 모은다: 시트 이름 '행사목록', 캘린더 이름 '주말 행사'(없으면 새로 만들고, '' 이면 기본 캘린더), 한 번에 받는 수 100, 최대 20쪽, 조회 시작일은 오늘보다 30일 전(이미 시작한 행사도 놓치지 않으려고), 캐시 6시간, 60일을 넘게 이어지는 행사는 '장기(상설)'.

[3. 데이터: 한국관광공사 국문 관광정보 서비스 (공공데이터포털)]
- 주소: https://apis.data.go.kr/B551011/KorService2/searchFestival2
- 항상 붙일 값: MobileOS=ETC, MobileApp=WeekendEvents, _type=json
- 조회 값: eventStartDate(YYYYMMDD), numOfRows, pageNo, arrange=A
- 응답: response.header.resultCode가 '0000'이면 정상. 목록은 response.body.items.item, 전체 건수는 response.body.totalCount. 결과가 1건이면 배열이 아니라 객체로, 0건이면 items가 빈 글자로 오니 항상 배열로 맞춘다.
- 쓸 항목: title, eventstartdate, eventenddate(둘 다 YYYYMMDD 글자), addr1, addr2, tel, mapx(경도), mapy(위도), contentid.
- pageNo를 늘려 가며 받다가, 빈 쪽이거나 totalCount만큼 모이면 멈춘다.

[4. 인증키와 오류]
- 코드에 키를 쓰지 않는다. 메뉴 ①에서 입력창으로 받아 PropertiesService.getUserProperties()에 저장한다. 키가 없으면 '인증키가 없어요. 메뉴에서 ① 인증키 등록을 먼저 해 주세요.'라고 알린다.
- 공공데이터포털의 인코딩 키와 디코딩 키 어느 쪽을 넣어도 되게 한다: 키에 '%'가 있으면 그대로, 없으면 encodeURIComponent로 딱 한 번만 인코딩해 serviceKey로 붙인다. 이중 인코딩 금지.
- 호출은 UrlFetchApp.fetch(url, {muteHttpExceptions: true}). 오류는 JSON이 아니라 XML 글자로 올 때가 많으니 JSON.parse 전에 글자부터 확인한다.
  - 'SERVICE_KEY' 또는 'SERVICE KEY'가 들어 있으면: '인증키 문제예요. 키를 다시 복사해 등록해 보세요. 방금 받은 키라면 반영에 시간이 걸릴 수 있어요.'
  - 'LIMITED_NUMBER_OF_SERVICE_REQUESTS'가 있으면: '오늘 호출 한도를 다 썼어요. 내일 다시 시도해 주세요.'
  - HTTP 200이 아니거나 JSON이 아니면 상태 코드, 응답 앞 100자와 함께 알린다.
- 같은 요청은 CacheService로 6시간 저장한다. 캐시 이름에는 인증키가 들어가지 않게 하고, 100KB를 넘으면 저장하지 않는다.

[5. 메뉴] 시트를 열 때(onOpen) '주말 행사 비서' 메뉴를 만든다.
① 인증키 등록 / ② 행사 찾기 / ③ 체크한 행사를 캘린더에 넣기

[6. ② 행사 찾기]
- 입력창 1: 지역이나 키워드(비우면 전국). 입력창 2: 기간 1 = 이번 주말, 2 = 앞으로 2주(비우면 1).
- 이번 주말 = 토·일. 오늘이 토요일이면 오늘~일요일, 일요일이면 오늘만. 시간대는 Session.getScriptTimeZone().
- API로 받은 행사를 코드로 직접 거른다: 기간이 겹치는 행사만(시작일이 끝 날짜보다 늦거나 종료일이 시작 날짜보다 빠르면 제외). 키워드가 있으면 행사명·addr1·addr2 안에서 찾는다.
- 정렬: 짧게 하는 행사를 위(시작일 빠른 순), 장기(상설) 행사는 아래(곧 끝나는 순).
- '행사목록' 시트를 비우고 새로 쓴다. 1행은 굵은 머리글(옅은 파란 배경)과 틀 고정. 열 순서: 선택(체크박스), 행사명, 시작일, 종료일, 장소(addr1 + addr2), 전화, 지도, 콘텐츠ID, 캘린더, 구분.
- 시작일·종료일은 yyyy-MM-dd 글자, 콘텐츠ID도 글자 서식('@')으로 넣어 날짜 자동변환이나 9.79E+12 같은 깨짐을 막는다.
- 지도 열: 좌표가 있으면 =HYPERLINK("https://map.kakao.com/link/map/행사명,위도,경도","지도 보기") (mapy가 위도, mapx가 경도, 행사명은 encodeURIComponent).
- 끝나면 토스트로 '전국 N건 중 (기간) 조건에 맞는 M건을 정리했어요. 가고 싶은 행사를 체크하세요!'. 0건이면 알림창으로 '조건에 맞는 행사가 없어요 / 기간을 늘리거나 키워드를 바꿔 보세요.'

[7. ③ 체크한 행사를 캘린더에 넣기]
- 체크했고 '캘린더' 열이 비어 있는 행만 대상. 없으면 '체크한 행사가 없어요. 가고 싶은 행사 앞 체크 칸을 눌러 주세요.'
- 반드시 확인창(예/아니오)을 띄운다: 'N개 행사를 "주말 행사" 캘린더에 등록할까요?' 예를 누르기 전에는 캘린더를 바꾸지 않는다.
- 행사마다 종일 일정으로 등록한다. 여러 날 행사는 끝나는 날의 다음 날 0시를 끝으로 넣어야 마지막 날이 포함된다(하루짜리는 시작일만 지정). 장소는 location에, 설명에는 장소·전화와 '(한국관광공사 TourAPI 제공 정보. 방문 전 행사 일정을 한 번 더 확인하세요.)'를 적는다.
- 같은 기간에 같은 제목의 일정이 이미 있으면 새로 만들지 않는다. 결과를 '캘린더' 열에 '등록됨' 또는 '이미 있음'으로 적고 선택 체크는 해제한다.
- 끝나면 토스트: 'N건 등록, M건은 이미 있어서 건너뛰었어요.'

[8. 오류 처리]
메뉴 동작 전체를 try/catch로 감싸고, 오류가 나면 알림창 제목 '앗, 문제가 생겼어요', 내용은 오류 메시지로 보여 준다.

[9. 점검용 함수]
인증키를 등록한 뒤 편집기에서 실행해 볼 testFetch()를 따로 만든다: 오늘부터 3건을 받아 전체 건수와 첫 번째 행사를 Logger.log로 출력.

/** 공공데이터포털 키는 '인코딩 키'와 '디코딩 키' 두 가지예요. 어느 쪽을 넣어도 되도록 맞춰 줍니다. */
function normalizeKey_(key) {
  return key.indexOf('%') >= 0 ? key : encodeURIComponent(key);

/**
 * TourAPI를 호출해서 JSON 결과를 돌려줍니다.
 * @param {string} operation  예: 'searchFestival2' (행사 정보 조회)
 * @param {Object} params     예: { eventStartDate: '20261101', numOfRows: 100, pageNo: 1 }
 */
function callApi_(operation, params) {
  // (1) 주소 만들기. MobileOS, MobileApp, _type 은 이 API가 항상 요구하는 기본 항목이에요.
  const query = Object.keys(params)
    .map(function (k) { return k + '=' + encodeURIComponent(params[k]); })
    .join('&');
  const publicUrl = BASE_URL + '/' + operation + '?MobileOS=ETC&MobileApp=WeekendEvents&_type=json&' + query;

  // (2) 캐시 확인 (인증키가 붙기 전의 주소로 확인하므로 키는 캐시 이름에 섞이지 않아요)
  const cache = CacheService.getUserCache();
  const cacheKey = makeCacheKey_(publicUrl);
  const cached = cache.get(cacheKey);
  if (cached) return JSON.parse(cached);

  // (3) 진짜로 물어보기
  const url = publicUrl + '&serviceKey=' + normalizeKey_(getApiKey_());
  const res = UrlFetchApp.fetch(url, { muteHttpExceptions: true });
  const code = res.getResponseCode();
  const text = res.getContentText();

  // (4) 답이 정상인지 확인. 공공데이터포털은 오류를 JSON이 아닌 XML 글자로 줄 때가 많아요.
  if (text.indexOf('SERVICE_KEY') >= 0 || text.indexOf('SERVICE KEY') >= 0) {
    throw new Error('인증키 문제예요. 키를 다시 복사해 등록해 보세요. 방금 받은 키라면 반영에 시간이 걸릴 수 있어요.');
  }
  if (text.indexOf('LIMITED_NUMBER_OF_SERVICE_REQUESTS') >= 0) {
    throw new Error('오늘 호출 한도를 다 썼어요. 내일 다시 시도해 주세요.');
  }
  if (code !== 200) {
    throw new Error('TourAPI 응답 오류 (HTTP ' + code + ')');
  }
  let data;
  try {
    data = JSON.parse(text);
  } catch (e) {
    throw new Error('예상과 다른 응답이 왔어요. (응답 앞부분: ' + text.slice(0, 100) + ')');
  }
  const header = (data.response || {}).header || {};
  if (header.resultCode && header.resultCode !== '0000') {
    throw new Error('TourAPI 오류: ' + (header.resultMsg || '') + ' (' + header.resultCode + ')');
  }

  // (5) 캐시에 저장 (한 칸 100KB 제한이라 너무 크면 건너뜀)
  if (text.length < 90000) cache.put(cacheKey, text, CACHE_SECONDS);
  return data;
}

function makeCacheKey_(text) {
  const bytes = Utilities.computeDigest(Utilities.DigestAlgorithm.MD5, text, Utilities.Charset.UTF_8);
  return bytes.map(function (b) { return ('0' + (b & 0xff).toString(16)).slice(-2); }).join('');
}

/**
 * 응답에서 행사 목록만 꺼냅니다. 모양: response.body.items.item
 * 결과가 1건이면 목록이 아니라 한 덩어리로, 0건이면 빈 글자('')로 오는 경우가 있어서 항상 '목록'으로 맞춰 줘요.
 */
function extractItems_(data) {
  const body = (data.response || {}).body || {};
  const items = body.items;
  if (!items || items === '') return [];
  const item = items.item;
  if (!item) return [];
  return Array.isArray(item) ? item : [item];
}

/** 행사를 쪽(page)별로 이어서 받아 한 목록으로 합칩니다. */
function fetchAllFestivals_(fromStr) {
  let all = [];
  let total = 0;
  for (let page = 1; page <= MAX_PAGES; page++) {
    const data = callApi_('searchFestival2', {
      eventStartDate: fromStr,
      numOfRows: PAGE_ROWS,
      pageNo: page,
      arrange: 'A'
    });
    const items = extractItems_(data);
    total = Number(((data.response || {}).body || {}).totalCount || 0);
    all = all.concat(items);
    if (items.length === 0 || all.length >= total) break;
  }
  return { items: all, total: total };
}

// 5. 조건에 맞게 거르기 (날짜·지역은 여기서 직접 걸러요)
//    ※ 날짜는 '20261114' 같은 8자리 글자라서, 글자끼리 비교해도 날짜 순서가 그대로 맞아요.

/** 이번 주말(토·일) 날짜를 돌려줍니다. 오늘이 토요일이면 '오늘~일요일', 일요일이면 '오늘'만이에요. */
function weekendWindow_(today, tz) {
  const dow = Number(Utilities.formatDate(today, tz, 'u')); // 1=월 ... 6=토, 7=일
  let sat;
  if (dow === 7) {
    sat = new Date(today.getTime() - 24 * 60 * 60 * 1000);   // 일요일이면 어제가 토요일
  } else {
    sat = new Date(today.getTime() + (6 - dow) * 24 * 60 * 60 * 1000);
  }
  const sun = new Date(sat.getTime() + 24 * 60 * 60 * 1000);
  const from = dow >= 6 ? today : sat;                       // 이미 주말이면 오늘부터
  return {
    from: Utilities.formatDate(from, tz, 'yyyyMMdd'),
    to: Utilities.formatDate(sun, tz, 'yyyyMMdd')
  };
}

/** 오늘부터 N일 동안의 기간을 돌려줍니다. */
function nextDaysWindow_(today, tz, days) {
  const end = new Date(today.getTime() + (days - 1) * 24 * 60 * 60 * 1000);
  return {
    from: Utilities.formatDate(today, tz, 'yyyyMMdd'),
    to: Utilities.formatDate(end, tz, 'yyyyMMdd')
  };
}

/** 시작일~종료일이 며칠인지 셉니다. ('20261001', '20261231' → 92) */
function daysBetween_(s, e) {
  s = String(s || '');
  e = String(e || '');
  if (s.length < 8 || e.length < 8) return 0;
  const a = Date.UTC(Number(s.slice(0, 4)), Number(s.slice(4, 6)) - 1, Number(s.slice(6, 8)));
  const b = Date.UTC(Number(e.slice(0, 4)), Number(e.slice(4, 6)) - 1, Number(e.slice(6, 8)));
  return Math.round((b - a) / (24 * 60 * 60 * 1000)) + 1;
}

/** 1년 내내 하는 상설 프로그램처럼 오래 이어지는 행사인지 확인합니다. */
function isLongRunning_(it) {
  return daysBetween_(it.eventstartdate, it.eventenddate) > LONG_DAYS;
}

/**
 * 받아 온 행사 중에서 (1) 기간이 겹치고 (2) 지역·키워드가 맞는 것만 남깁니다.
 * 키워드는 행사명과 주소 안에서 찾아요. 예: '김포' → '경기도 김포시 ...' 주소가 걸려요.
 *
 * 정렬: 짧게 하는 행사를 위에(시작일 빠른 순), 오래 하는 상설 행사는 아래에(곧 끝나는 순) 둡니다.
 */
function filterEvents_(items, keyword, fromStr, toStr) {
  const kw = (keyword || '').trim();
  return items
    .filter(function (it) {
      const s = String(it.eventstartdate || '');
      const e = String(it.eventenddate || '');
      if (!s || !e) return false;
      if (s > toStr || e < fromStr) return false;   // 기간이 겹치지 않으면 제외
      if (!kw) return true;
      const hay = (it.title || '') + ' ' + (it.addr1 || '') + ' ' + (it.addr2 || '');
      return hay.indexOf(kw) >= 0;
    })
    .sort(function (a, b) {
      const la = isLongRunning_(a);
      const lb = isLongRunning_(b);
      if (la !== lb) return la ? 1 : -1;                                              // 짧은 행사가 먼저
      if (la) return String(a.eventenddate).localeCompare(String(b.eventenddate));    // 상설은 곧 끝나는 순
      return String(a.eventstartdate).localeCompare(String(b.eventstartdate));        // 짧은 행사는 빨리 시작하는 순
    });
}

/** '20261114' → '2026-11-14' */
function fmtDate_(s) {
  s = String(s || '');
  return s.length === 8 ? s.slice(0, 4) + '-' + s.slice(4, 6) + '-' + s.slice(6, 8) : s;
}

function writeEventsToSheet_(events) {
  const ss = SpreadsheetApp.getActive();
  const sheet = ss.getSheetByName(SHEET_NAME) || ss.insertSheet(SHEET_NAME);
  sheet.clear();   // 새로 찾을 때마다 목록을 새로 만들어요 (이미 등록한 행사는 ③ 단계에서 캘린더를 확인해 중복을 막아요)

  sheet.getRange(1, 1, 1, COLS).setValues([HEADER]).setFontWeight('bold').setBackground('#e8eaf6');
  sheet.setFrozenRows(1);
  if (events.length === 0) return 0;

  const rows = events.map(function (it) {
    const title = it.title || '';
    const hasPos = it.mapx && it.mapy;
    // 카카오맵 링크: 이름,위도,경도 순서예요. (mapy=위도, mapx=경도)
    const mapFormula = hasPos
      ? '=HYPERLINK("https://map.kakao.com/link/map/' + encodeURIComponent(title) + ',' + it.mapy + ',' + it.mapx + '","지도 보기")'
      : '';
    return [
      false,
      title,
      fmtDate_(it.eventstartdate),
      fmtDate_(it.eventenddate),
      ((it.addr1 || '') + ' ' + (it.addr2 || '')).trim(),
      it.tel || '',
      mapFormula,
      String(it.contentid || ''),
      '',
      isLongRunning_(it) ? '장기(상설)' : ''
    ];
  });

  // 날짜·콘텐츠ID는 '글자'로 저장해야 날짜 자동변환이나 9.79E+12 같은 깨짐이 없어요.
  sheet.getRange(2, 3, rows.length, 2).setNumberFormat('@');
  sheet.getRange(2, 8, rows.length, 1).setNumberFormat('@');
  sheet.getRange(2, 1, rows.length, COLS).setValues(rows);
  sheet.getRange(2, 1, rows.length, 1).insertCheckboxes();   // 선택 칸을 체크박스로

  sheet.setColumnWidth(2, 280);
  sheet.setColumnWidth(5, 280);
  return rows.length;
}

/**

 * @return {string} '등록됨' 또는 '이미 있음'

function addEventToCalendar_(cal, row, tz) {
  const title = String(row[1]);
  const start = Utilities.parseDate(String(row[2]), tz, 'yyyy-MM-dd');
  const end = Utilities.parseDate(String(row[3]), tz, 'yyyy-MM-dd');
  const endExclusive = new Date(end.getTime() + 24 * 60 * 60 * 1000);  // 종일 일정은 '끝나는 날의 다음 날 0시'까지로 넣어야 마지막 날이 포함돼요

  const dup = cal.getEvents(start, endExclusive, { search: title })
    .filter(function (ev) { return ev.getTitle() === title; });
  if (dup.length > 0) return '이미 있음';

  const description =
    '장소: ' + row[4] + '\n' +
    (row[5] ? '전화: ' + row[5] + '\n' : '') +
    '(한국관광공사 TourAPI 제공 정보. 방문 전 행사 일정을 한 번 더 확인하세요.)';
  const options = { location: String(row[4]), description: description };

  if (String(row[2]) === String(row[3])) {
    cal.createAllDayEvent(title, start, options);                 // 하루짜리
  } else {
    cal.createAllDayEvent(title, start, endExclusive, options);   // 여러 날
  }
  return '등록됨';
}

[2. 환경]
- 구글 시트에 연결된 Apps Script(컨테이너 바인딩). 파일은 Code.gs 하나. 외부 서버와 라이브러리는 쓰지 않는다.
- 초보자가 읽을 수 있게 한국어 주석을 충분히 달고, 코드를 '설정값 / 메뉴 / 인증키 / API 호출 / 시트 쓰기 / 소장·대출 확인 / 메뉴 동작' 구역으로 나눈다.
- 코드 맨 위에 const로 설정값을 모은다: 검색 결과 시트 '책검색결과', 소장 결과 시트 '소장현황', 한 번에 가져올 책 수 30, 캐시 6시간, 지역 코드 '31'(경기도), 동네 이름 '김포'(도서관 이름이나 주소에 이 글자가 있는 곳만 사용), 소장 도서관 목록 최대 10쪽, 대출 확인할 도서관 최대 30곳. 지역 코드와 동네 이름은 나중에 바꿔 쓸 수 있게 눈에 띄는 주석을 단다.

[3. 데이터: 도서관 정보나루 (data4library.kr)]
- 기본 주소 https://data4library.kr/api/ 뒤에 서비스 이름을 붙인다. 모든 호출에 format=json과 authKey를 붙인다. 파라미터 값은 encodeURIComponent로 한 번만 인코딩한다.
- 책 검색 srchBooks: keyword, pageNo=1, pageSize=30. 응답은 response.numFound(전체 건수)와 response.docs 배열이고, 배열의 각 원소 안 doc에 bookname, authors, publisher, publication_year, isbn13, loan_count, bookImageURL이 있다.
  주의: 이 검색은 제목 말고 저자 등에서 찾은 책도 섞어 준다. 그래서 받은 책 중 제목(bookname)에 검색어가 들어 있는 책만 남긴다(띄어쓰기와 대소문자는 무시).
- 이 책을 가진 도서관 libSrchByBook: isbn, region(지역 코드), pageNo, pageSize=100. 응답 response.libs 배열의 각 원소 안 lib에 libCode, libName, address, tel, latitude, longitude. 새 도서관이 더 안 나올 때까지 쪽을 넘기되 최대 10쪽. 이 중 libName이나 address에 동네 이름이 든 곳만 쓴다.
- 도서관별 대출 가능 여부 bookExist: libCode, isbn13. 응답 response.result.hasBook(소장 Y/N), response.result.loanAvailable(대출 가능 Y/N). 자주 바뀌는 정보라 이 호출만은 캐시하지 않는다.
- 오류: 응답에 response.error가 있으면 '정보나루 오류: (그 문구)'로 알린다. HTTP 200이 아니면 상태 코드와 함께, JSON이 아니면 '인증키가 맞는지 확인해 주세요'와 응답 앞 100자와 함께 알린다.
- 같은 요청은 CacheService로 6시간 저장한다. 캐시 이름에는 인증키가 들어가지 않게 하고, 100KB를 넘으면 저장하지 않는다.

[6. ② 책 검색하기]
- 입력창에서 책 제목이나 키워드를 받는다. 제목 필터를 거친 뒤 0권이면 알림창으로 '제목에 "(검색어)"가 들어간 책이 없어요'와 함께 저자 이름으로는 찾을 수 없다고 알려 준다.
- '책검색결과' 시트 열 순서: 검색일시, 검색어, 제목, 저자, 출판사, 출판연도, ISBN13, 대출건수, 표지. 1행은 굵은 머리글(옅은 파란 배경)과 틀 고정.
- 최신 검색이 맨 위에 오게 한다: appendRow가 아니라 2행에 insertRowsBefore(2, 새 줄 수)로 끼워 넣고, 새 줄은 clearFormat()으로 서식을 비운 뒤 쓴다.
- ISBN13은 글자 서식('@')으로 넣어 9.79E+12 같은 깨짐을 막는다. 검색일시는 yyyy-MM-dd HH:mm 서식. 표지는 =IMAGE("표지 주소"). 줄 높이 80, 세로 가운데 정렬, 제목과 저자 칸은 줄바꿈.
- 제목 정리: 정보나루 제목은 '아몬드 :손원평 장편소설'처럼 공백 뒤에 ':' '/' '=' 가 오고 덧붙은 말이 붙는다. 그 앞까지만 제목으로 쓴다.
- 저자 정리: '지은이:' '옮긴이:' 같은 표기를 지우고, 여러 명은 ';' 대신 ', '로 잇는다.
- 끝나면 토스트로 몇 권을 시트에 넣었는지 알린다.

[7. ③ 소장·대출 확인]
- '책검색결과' 시트에서 클릭해 둔 줄의 책을 확인한다. 다른 시트이거나 머리글을 눌렀으면 안내 문구를 알림창으로 보여 주고, ISBN13이 비어 있으면 확인할 수 없다고 알린다.
- 순서: (1) libSrchByBook으로 이 책을 가진 도서관 목록 받기 (2) 우리 동네만 거르기 (3) 도서관마다 bookExist로 소장·대출 가능 여부 묻기. 한 곳이 실패해도 나머지는 계속하고, 실패한 곳은 '확인 불가'로 적는다.
- 동네 도서관이 하나도 없으면 알림창: '"(동네 이름)" 도서관에서 찾지 못했어요 / 정보나루에 정보를 공개한 도서관만 나와서, 실제로는 있어도 안 보일 수 있어요.'
- '소장현황' 시트 열 순서: 확인일시, 책 제목, ISBN13, 도서관, 소장, 대출, 전화, 주소, 지도. 이것도 최신 확인이 맨 위에 오게 insertRowsBefore로 쓴다. ISBN13은 글자 서식.
- 소장 열: hasBook이 Y면 '있음', N이면 '없음', 그 밖에는 '확인 불가'. 대출 열: 소장이 없으면 '-', loanAvailable이 Y면 '대출 가능', N이면 '대출 중', 그 밖에는 '확인 불가'. '대출 가능' 칸은 연한 초록(#e6f4ea), '대출 중' 칸은 연한 분홍(#fdecea) 배경.
- 지도 열: 좌표가 있으면 =HYPERLINK("https://map.kakao.com/link/map/도서관이름,위도,경도","지도 보기").
- 끝나면 토스트: '"(책 제목)": (동네) 도서관 N곳 중 M곳에서 지금 빌릴 수 있어요.'

/**
 * 정보나루 API를 호출해서 JSON 결과를 돌려줍니다.
 * @param {string} endpoint  예: 'srchBooks' (책 검색)
 * @param {Object} params    예: { keyword: '아몬드', pageNo: 1, pageSize: 10 }
 * @param {boolean} fresh    true면 저장해 둔 답을 쓰지 않고 매번 새로 물어봐요 (대출 가능 여부처럼 자주 바뀌는 정보용)
 */
function callApi_(endpoint, params, fresh) {
  // (1) 주소 만들기: 주소?이름=값&이름=값 ... 형태. 한글은 encodeURIComponent로 변환해야 해요.
  const query = Object.keys(params)
    .map(function (k) { return encodeURIComponent(k) + '=' + encodeURIComponent(params[k]); })
    .join('&');
  const publicUrl = BASE_URL + '/' + endpoint + '?' + query + '&format=json';

  // (2) 캐시 확인: 같은 질문을 이미 했다면 정보나루에 다시 묻지 않고 저장해 둔 답을 씁니다.
  //     (인증키가 들어가기 전의 주소로 확인하므로 키는 캐시 이름에 섞이지 않아요)
  const cache = CacheService.getUserCache();
  const cacheKey = makeCacheKey_(publicUrl);
  const cached = fresh ? null : cache.get(cacheKey);
  if (cached) return JSON.parse(cached);

  // (3) 진짜로 물어보기: 여기서 처음으로 인증키를 꺼내 붙입니다.
  const url = publicUrl + '&authKey=' + encodeURIComponent(getApiKey_());
  const res = UrlFetchApp.fetch(url, { muteHttpExceptions: true });  // 오류가 나도 멈추지 말고 알려 달라는 옵션
  const code = res.getResponseCode();
  const text = res.getContentText();

  // (4) 답이 정상인지 확인
  if (code !== 200) {
    throw new Error('정보나루 응답 오류 (HTTP ' + code + ')');
  }
  let data;
  try {
    data = JSON.parse(text);
  } catch (e) {
    throw new Error('예상과 다른 응답이 왔어요. 인증키가 맞는지 확인해 주세요. (응답 앞부분: ' + text.slice(0, 100) + ')');
  }
  if (data.response && data.response.error) {
    throw new Error('정보나루 오류: ' + data.response.error);
  }

  // (5) 다음을 위해 캐시에 저장 (캐시 한 칸은 100KB까지라서 너무 크면 건너뜀)
  if (!fresh && text.length < 90000) cache.put(cacheKey, text, CACHE_SECONDS);
  return data;
}

/** 긴 주소를 짧은 고정 길이 이름표(MD5)로 바꿔서 캐시 이름으로 씁니다. */
function makeCacheKey_(text) {
  const bytes = Utilities.computeDigest(Utilities.DigestAlgorithm.MD5, text, Utilities.Charset.UTF_8);
  return bytes.map(function (b) { return ('0' + (b & 0xff).toString(16)).slice(-2); }).join('');
}

/**
 * 키워드로 책을 검색합니다.
 * 정보나루의 답은 { response: { numFound, docs: [ { doc: {...책 한 권...} }, ... ] } } 모양이에요.
 * 그래서 docs 안의 doc만 꺼내서 '책 한 권 = 한 덩어리' 목록으로 정리합니다.
 */
function searchBooks_(keyword) {
  const data = callApi_('srchBooks', { keyword: keyword, pageNo: 1, pageSize: PAGE_SIZE });
  const r = data.response || {};
  const fetched = (r.docs || []).map(function (d) { return d.doc; });
  // 정보나루는 제목 말고 저자 등에서 찾은 책도 섞어 주는 것으로 보여요. 그래서 제목에 검색어가 든 책만 남깁니다.
  const books = fetched.filter(function (b) { return titleHas_(b, keyword); });
  return { total: Number(r.numFound || 0), fetched: fetched.length, books: books };
}

/** 책 제목에 검색어가 들어 있는지 확인합니다. (띄어쓰기와 대소문자는 무시해요) */
function titleHas_(book, keyword) {
  const norm = function (s) { return String(s || '').replace(/\s+/g, '').toLowerCase(); };
  return norm(book.bookname).indexOf(norm(keyword)) >= 0;
}

// ============================================================
function writeBooksToSheet_(keyword, books) {
  if (books.length === 0) return 0;

  const ss = SpreadsheetApp.getActive();
  const sheet = ss.getSheetByName(SHEET_NAME) || ss.insertSheet(SHEET_NAME);

  // 처음이면 제목 줄(머리글)을 만듭니다.
  const header = ['검색일시', '검색어', '제목', '저자', '출판사', '출판연도', 'ISBN13', '대출건수', '표지'];
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(header);
    sheet.getRange(1, 1, 1, header.length).setFontWeight('bold').setBackground('#e8eaf6');
    sheet.setFrozenRows(1);
  }

  // 책 한 권 = 시트 한 줄. 정보나루의 항목 이름(bookname, authors ...)을 칸 순서에 맞게 배치합니다.
  const now = new Date();
  const rows = books.map(function (b) {
    return [
      now,
      keyword,
      cleanTitle_(b.bookname),
      cleanAuthors_(b.authors),
      b.publisher || '',
      b.publication_year || '',
      String(b.isbn13 || ''),
      Number(b.loan_count || 0),
      b.bookImageURL ? '=IMAGE("' + b.bookImageURL + '")' : ''
    ];
  });

  // 최신 검색이 맨 위에 오도록, 머리글 바로 아래(2번째 줄)에 새 줄을 끼워 넣어요.
  const startRow = 2;
  sheet.insertRowsBefore(startRow, rows.length);
  sheet.getRange(startRow, 1, rows.length, header.length).clearFormat();   // 머리글 모양이 따라오지 않게 새 줄은 서식을 비워요
  // ISBN은 숫자처럼 보여도 '글자'로 저장해야 해요. (안 그러면 9.79E+12 처럼 깨져요. 다음 레벨에서 이 값을 다시 읽어 씁니다)
  sheet.getRange(startRow, 7, rows.length, 1).setNumberFormat('@');
  sheet.getRange(startRow, 1, rows.length, 1).setNumberFormat('yyyy-MM-dd HH:mm');
  sheet.getRange(startRow, 1, rows.length, header.length).setValues(rows);

  // 표지 그림이 보이도록 줄 높이와 칸 너비 조정, 글자는 칸 가운데(세로)에 맞춰 긴 제목은 줄바꿈
  const widths = [140, 90, 260, 190, 120, 80, 130, 80, 70];   // 칸 순서: 검색일시 … 표지
  widths.forEach(function (w, i) { sheet.setColumnWidth(i + 1, w); });
  sheet.setRowHeights(startRow, rows.length, 80);
  const body = sheet.getRange(startRow, 1, rows.length, header.length);
  body.setVerticalAlignment('middle');
  sheet.getRange(startRow, 3, rows.length, 2).setWrapStrategy(SpreadsheetApp.WrapStrategy.WRAP);
  return rows.length;
}

/**
 * 제목 뒤에 붙은 부제·저자 표기를 떼어 냅니다.
 * 정보나루 제목은 '아몬드 :손원평 장편소설' 처럼 ' :' 나 ' /' 뒤에 덧붙은 말이 있어요.
 */
function cleanTitle_(name) {
  const t = String(name || '').split(/\s+[:\/=]/)[0].trim();
  return t || String(name || '').trim();
}

/** 저자 앞의 '지은이:' 같은 표기를 지우고, 여러 명은 쉼표로 이어 줍니다. */
function cleanAuthors_(authors) {
  return String(authors || '')
    .replace(/(^|;)\s*(지은이|지은이들|저자|글|그림|옮긴이|엮은이)\s*:\s*/g, '$1 ')
    .split(/\s*;\s*/)
    .map(function (s) { return s.trim(); })
    .filter(function (s) { return s; })
    .join(', ');
}

// 6. 소장·대출 확인 (레벨 2)
//    ISBN13은 책마다 붙은 '주민번호' 같은 번호예요. 이 번호로 도서관마다 같은 책을 찾아요.
//    순서: (1) 이 책을 가진 도서관 목록 받기 → (2) 우리 동네만 거르기 → (3) 도서관별로 '지금 빌릴 수 있나' 묻기
// ============================================================

/** ISBN으로 '이 책을 가진 도서관' 목록을 받아 와서, 우리 동네(MY_AREA_WORD)만 남깁니다. */
function findLocalLibraries_(isbn13) {
  const seen = {};
  const all = [];
  for (let page = 1; page <= MAX_LIB_PAGES; page++) {
    const data = callApi_('libSrchByBook', { isbn: isbn13, region: MY_REGION_CODE, pageNo: page, pageSize: 100 });
    const libs = ((data.response || {}).libs || []).map(function (x) { return x.lib || x; });
    let added = 0;
    libs.forEach(function (lib) {
      const code = String(lib.libCode || '');
      if (code && !seen[code]) { seen[code] = true; all.push(lib); added++; }
    });
    if (added === 0) break;   // 새로 받은 도서관이 없으면 여기서 끝내요
  }
  const local = all.filter(function (lib) {
    return (String(lib.libName || '') + ' ' + String(lib.address || '')).indexOf(MY_AREA_WORD) >= 0;
  });
  return { regionCount: all.length, local: local };
}

/** 도서관 한 곳에 이 책이 있는지, 지금 빌릴 수 있는지 확인합니다. (자주 바뀌는 정보라 매번 새로 물어봐요) */
function checkBookInLibrary_(libCode, isbn13) {
  const data = callApi_('bookExist', { libCode: libCode, isbn13: isbn13 }, true);
  const resp = data.response || {};
  const r = resp.result || resp;
  return { hasBook: String(r.hasBook || ''), loanAvailable: String(r.loanAvailable || '') };
}

/** 우리 동네 도서관들을 하나씩 돌며 소장·대출 가능 여부를 확인합니다. 한 곳이 실패해도 나머지는 계속해요. */
function checkLibraries_(libs, isbn13) {
  return libs.slice(0, MAX_LIBS_TO_CHECK).map(function (lib) {
    let status;
    try {
      status = checkBookInLibrary_(lib.libCode, isbn13);   // 도서관마다 따로 물어봐요
    } catch (e) {
      status = { hasBook: '', loanAvailable: '' };
    }
    return { lib: lib, status: status };
  });
}

/** Y/N 같은 답을 사람이 읽는 말로 바꿉니다. */
function holdingLabels_(st) {
  const has = st.hasBook === 'Y' ? '있음' : (st.hasBook === 'N' ? '없음' : '확인 불가');
  let loan = '확인 불가';
  if (st.hasBook === 'N') loan = '-';
  else if (st.loanAvailable === 'Y') loan = '대출 가능';
  else if (st.loanAvailable === 'N') loan = '대출 중';
  return { has: has, loan: loan };
}

/** 확인 결과를 '소장현황' 시트에 이어서 적습니다. */
function writeHoldingsToSheet_(title, isbn13, items) {
  const ss = SpreadsheetApp.getActive();
  const sheet = ss.getSheetByName(HOLDINGS_SHEET) || ss.insertSheet(HOLDINGS_SHEET);

  const header = ['확인일시', '책 제목', 'ISBN13', '도서관', '소장', '대출', '전화', '주소', '지도'];
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(header);
    sheet.getRange(1, 1, 1, header.length).setFontWeight('bold').setBackground('#e8eaf6');
    sheet.setFrozenRows(1);
    [140, 200, 130, 200, 70, 90, 120, 280, 90].forEach(function (w, i) { sheet.setColumnWidth(i + 1, w); });
  }

  const now = new Date();
  const rows = items.map(function (it) {
    const lib = it.lib;
    const lab = holdingLabels_(it.status);
    const hasPos = lib.latitude && lib.longitude;
    const map = hasPos
      ? '=HYPERLINK("https://map.kakao.com/link/map/' + encodeURIComponent(lib.libName || '') + ',' + lib.latitude + ',' + lib.longitude + '","지도 보기")'
      : '';
    return [now, title, isbn13, lib.libName || '', lab.has, lab.loan, lib.tel || '', lib.address || '', map];
  });

  // 최신 확인 결과가 맨 위에 오도록 머리글 바로 아래에 끼워 넣어요.
  const startRow = 2;
  sheet.insertRowsBefore(startRow, rows.length);
  sheet.getRange(startRow, 1, rows.length, header.length).clearFormat();
  sheet.getRange(startRow, 3, rows.length, 1).setNumberFormat('@');          // ISBN은 글자로
  sheet.getRange(startRow, 1, rows.length, 1).setNumberFormat('yyyy-MM-dd HH:mm');
  sheet.getRange(startRow, 1, rows.length, header.length).setValues(rows);

  // 대출 칸 색: 가능=초록, 대출 중=분홍
  rows.forEach(function (r, i) {
    const cell = sheet.getRange(startRow + i, 6);
    if (r[5] === '대출 가능') cell.setBackground('#e6f4ea');
    else if (r[5] === '대출 중') cell.setBackground('#fdecea');
  });
  return rows.length;
}

/** 화면에서 호출: 책 한 권의 우리 동네 소장·대출 가능 여부. 결과는 '소장현황' 시트에도 저장해요. */
function dashCheck(isbn, title) {
  const isbn13 = String(isbn || '').trim();
  if (!isbn13) throw new Error('이 책은 ISBN13이 없어서 확인할 수 없어요.');
  const found = findLocalLibraries_(isbn13);
  const items = checkLibraries_(found.local, isbn13);
  if (items.length > 0) writeHoldingsToSheet_(String(title || ''), isbn13, items);
  const tz = Session.getScriptTimeZone();
  return {
    at: Utilities.formatDate(new Date(), tz, 'MM-dd HH:mm'),
    libs: items.map(function (it) {
      const lab = holdingLabels_(it.status);
      const hasPos = it.lib.latitude && it.lib.longitude;
      return {
        name: String(it.lib.libName || ''),
        has: lab.has,
        loan: lab.loan,
        tel: String(it.lib.tel || ''),
        address: String(it.lib.address || ''),
        map: hasPos ? 'https://map.kakao.com/link/map/' + encodeURIComponent(it.lib.libName || '') + ',' + it.lib.latitude + ',' + it.lib.longitude : ''
      };
    })
  };
}

/**
 * 화면에서 호출: 대시보드를 열 때 보여 줄 '최근 검색한 책'(최신순) 목록.
 * 시트의 검색일시를 기준으로 정렬하고, 같은 책은 한 번만, 가장 최근 소장·대출 확인 결과를 붙여 줘요.
 */
function dashRecent() {
  const ss = SpreadsheetApp.getActive();
  const tz = Session.getScriptTimeZone();
  const timeOf = function (v) { return v && typeof v.getTime === 'function' ? v.getTime() : 0; };
  const sheet = ss.getSheetByName(SHEET_NAME);
  if (!sheet || sheet.getLastRow() < 2) return [];

  // (1) 책검색결과: 최근 300줄을 읽어 최신순으로 정렬
  const n = Math.min(sheet.getLastRow() - 1, 300);
  const vals = sheet.getRange(2, 1, n, 9).getValues();
  const forms = sheet.getRange(2, 9, n, 1).getFormulas();
  const rows = vals.map(function (v, i) { return { v: v, f: String(forms[i][0] || ''), t: timeOf(v[0]) }; });
  rows.sort(function (a, b) { return b.t - a.t; });

  // (2) 소장현황: 책(ISBN)마다 가장 최근에 확인한 묶음만 모아 둠
  const latest = {};
  const hs = ss.getSheetByName(HOLDINGS_SHEET);
  if (hs && hs.getLastRow() >= 2) {
    const m = Math.min(hs.getLastRow() - 1, 400);
    const hv = hs.getRange(2, 1, m, 9).getValues();
    const hf = hs.getRange(2, 9, m, 1).getFormulas();
    hv.forEach(function (v, i) {
      const isbn = String(v[2] || '').trim();
      if (!isbn) return;
      const t = timeOf(v[0]);
      if (!latest[isbn] || t > latest[isbn].t) latest[isbn] = { t: t, libs: [] };
      if (latest[isbn].t !== t) return;   // 더 오래된 확인 결과는 건너뜀
      const mm = String(hf[i][0] || '').match(/"(https:\/\/map\.kakao\.com[^"]*)"/);
      latest[isbn].libs.push({
        name: String(v[3] || ''), has: String(v[4] || ''), loan: String(v[5] || ''),
        tel: String(v[6] || ''), address: String(v[7] || ''), map: mm ? mm[1] : ''
      });
    });
  }

  // (3) 같은 책은 한 번만, 최대 24권
  const seen = {};
  const books = [];
  rows.forEach(function (r) {
    const isbn = String(r.v[6] || '').trim();
    if (!isbn || seen[isbn] || books.length >= 24) return;
    seen[isbn] = true;
    const img = r.f.match(/IMAGE\("([^"]+)"\)/);
    const h = latest[isbn];
    books.push({
      title: String(r.v[2] || ''),
      authors: String(r.v[3] || ''),
      publisher: String(r.v[4] || ''),
      year: String(r.v[5] || ''),
      isbn: isbn,
      loans: Number(r.v[7] || 0),
      cover: img ? img[1] : '',
      searchedAt: r.t ? Utilities.formatDate(new Date(r.t), tz, 'MM-dd HH:mm') : '',
      holdings: h ? { at: Utilities.formatDate(new Date(h.t), tz, 'MM-dd HH:mm'), libs: h.libs } : null
    });
  });
  return books;
}
